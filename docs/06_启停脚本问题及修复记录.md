## 问题 #1：agent-quality-gate.sh 退出代码 1

### 发现时间
2026-03-11

### 问题现象

运行 `agent-quality-gate.sh` 时脚本退出码为 1，表示质量门禁未通过：

```
[0;31m✗ FAIL[0m: ruff format — 不一致 (运行 'uv run ruff format dispatcher' 修复)

[0;34m═══════════════════════════════════════════════════[0m
[0;34m  质量门禁汇总[0m
[0;34m═══════════════════════════════════════════════════[0m
  [0;32m通过: 2[0m  [0;31m失败: 1[0m  [1;33m跳过: 0[0m

  [0;31m质量门禁未通过！[0m
```

### 根因分析

**直接原因**：`dispatcher/core.py` 和 `dispatcher/vk_db.py` 两个文件的代码格式不符合 ruff format 规范。

**根本原因**：
1. 开发过程中新增/修改代码时，未运行 `ruff format` 格式化
2. 这两个文件包含较长的函数调用，参数换行方式不符合 ruff 默认格式化规则

**具体代码位置**：
- `dispatcher/vk_db.py:362-369` — `logger.warning()` 调用参数换行格式不一致

修复前的格式：
```python
logger.warning(
    "VKDatabase.is_coding_timed_out: 分支 %s %s 已运行 %.0f 分钟，超过阈值 %d 分钟，认定超时",
    branch, run_reason, elapsed.total_seconds() / 60, max_minutes,
)
```

修复后的格式（ruff 标准格式）：
```python
logger.warning(
    "VKDatabase.is_coding_timed_out: 分支 %s %s 已运行 %.0f 分钟，超过阈值 %d 分钟，认定超时",
    branch,
    run_reason,
    elapsed.total_seconds() / 60,
    max_minutes,
)
```

### 修复方案

**步骤 1**：运行 ruff format 格式化代码
```bash
uv run ruff format dispatcher/
```

**步骤 2**：验证质量门禁通过
```bash
bash scripts/agent-quality-gate.sh
```

**预期输出**：
```
[0;32m✓ PASS[0m: ruff format — 格式一致
[0;32m质量门禁全部通过 ✓[0m
```

### 预防措施

1. **提交前检查**：在 git commit 前运行 `make quality-gate` 或 `uv run ruff format .`
2. **IDE 集成**：配置编辑器保存时自动格式化（使用 ruff）
3. **pre-commit hook**：可考虑添加 pre-commit hook 自动格式化

|------|---------|

| `dispatcher/vk_db.py` | 格式化 |
